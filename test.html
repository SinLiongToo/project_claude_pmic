Chapter 5 · Test & qualification

測試：量得準，才知道它好不好

電源 IC 的測試分三種：量產時在 ATE 上用最短時間篩出壞品；在實驗室把每個參數在所有條件下量清楚（特性化）；以及用加速應力證明它能活過產品壽命（可靠度驗證）。三者量到的數字要能互相對得起來，否則客訴時誰也說服不了誰。

DC-DC 參數

  • 效率：η = POUT/PIN，四線量測電壓、精密分流量電流，每個負載點等熱平衡。1% 的量測誤差就足以讓效率曲線「看起來」不同。
  • RDS(on)：用測試模式把高側或低側固定導通，灌入已知電流，以 Kelvin 量測跨壓。
  • 切換頻率與最小導通時間：量 SW 波形；量產可用內部振盪器的分頻輸出，避免接大電感。
  • 峰值 / 谷值限流：逐週期限流門檻，需要實際電感或測試模式。
  • 輕載模式切換點、漣波、負載暫態：多數屬於特性化項目，量產只做功能確認。

ATE 量產測試

電源 IC 的 ATE（例如混合訊號測試機）有多組 DPS（裝置電源）、PMU（精密量測單元）、高電流 / 高電壓源、數位通道與數位化器（digitizer）。量產測試的核心問題是在 0.5 秒內量完所有保證參數，又不能犧牲精度。

  • 穩定時間：LDO 輸出接大電容時，每改一次條件都要等數 ms 到數十 ms。量產測試通常在 load board 上用較小的電容，或用繼電器切換。
  • 測試模式：透過特殊腳位序列或 I²C 命令進入測試模式，把內部節點（參考電壓、偏壓電流、振盪器）接到類比多工器輸出，直接量測，也可以關閉軟啟動或保護以縮短時間。
  • 多站：4–32 站平行測試；站間共用資源（例如精密數位化器）會讓平行效率下降。
  • Load board 設計：大電流路徑的寄生電阻與電感、繼電器壽命、熱設計都影響量測。load board 本身也要做定期驗證與保養。
  • 測試程式版本管理：每次修改測試極限、項目或演算法都要記錄並驗證相關性，車用產品還要通知客戶。

大量 ATE 測試：產能與成本

量產測試的目標是用最少的機台時間，保證出貨的每一顆都符合規格。決定成本的是三件事：每顆要測多久、一次能測幾顆、機台有多少時間真的在測。這一節說明測試單元的組成、UPH 與測試成本怎麼算、縮短測試時間的方法，以及重測與分 bin 的規則。文中的數字都是量級，實際依產品與工廠而定。

車用產品常要求在多個溫度測試（例如低溫、室溫、高溫）。每多一個溫度通常就多一次插入（insertion），測試成本幾乎跟著倍增，所以哪些項目一定要在每個溫度測、哪些可以只在一個溫度測加上保護帶，是重要的成本決策，要有特性化資料支持。

UPH 與平行效率

UPH（units per hour）是一個測試單元每小時能測的顆數。多站測試時，N 顆一起下壓、一起測，但測試時間會比單站長一點，因為有些資源要輪流用。用平行效率（PTE）描述：

TN = T1 × [1 + (N − 1)(1 − PTE)]　　UPH = 3600 × N / (TN + tindex) × OEE / (1 + 重測率)

PTE = 100% 代表 N 站和 1 站一樣快；tindex 是 handler 每次換料、下壓的時間，這段時間測試機在等。OEE（設備綜合效率）扣掉換批、保養、故障、等料等時間。例：T1 = 0.6 s、8 站、PTE 95%、index 0.4 s → T8 = 0.81 s，每次下壓 1.21 s，理論 UPH 約 23 800；OEE 85%、重測 3% 後約 19 600。

平行效率低於 100% 的常見原因：共用的精密或大電流資源、需要逐站做的修調燒錄、測試程式與通訊的固定開銷。還有一點常被忽略：多站時「遇到第一個失敗就停止」幫助不大，因為失敗那站停了，其他站還在測，整次下壓的時間不會變短。

測試成本怎麼算

每顆測試成本 = 機時費率 / UPH × 插入次數　　每顆良品的測試成本 = 每顆測試成本 / 良率

機時費率是測試單元每小時的完整成本：測試機與 handler 的折舊、廠房、電力、人力、保養，以及 socket、探針卡等耗材。費率依機台等級與地區差異很大，下面計算器用的是可以自己調整的假設值。對售價很低的小顆電源 IC，測試成本占產品成本的比例可能相當顯著，所以每省 0.1 s 都有意義。

縮短測試時間的方法

  • 減少等待：量產 load board 用較小的電容或用繼電器切換，用測試模式關掉軟啟動、縮短保護延遲。電源 IC 的測試時間大多花在「等穩定」而不是「量」。
  • 同時量不同區塊（concurrent test）：例如 PMIC 的多路 Buck 同時量，需要 DFT 支援和足夠的資源。
  • 每站獨立的資源：避免多站共用數位化器或大電流源，平行效率才會高；這是機台成本與測試時間的取捨。
  • 刪除冗餘項目：特性化證明兩個參數高度相關時只測一個；Cpk 很高且長期穩定的項目可改為抽測。要有統計依據、經過審查，車用產品還要客戶同意。
  • 適應性測試（adaptive test）：依批次歷史或前面的結果動態增減項目，例如新批次先全測、穩定後減測，出現異常時自動加回。
  • 把項目放在對的插入：低電流、要修調的項目在 CP 做（成本低，修調也只能在封裝前）；需要封裝或大電流的放在 FT（見生產流程）。
  • 修調演算法：用二分搜尋取代線性掃描，先寫暫存器試修、確認後一次燒錄。
  • 插入次數：每個溫度一次插入是最大的成本項。能證明室溫結果加保護帶可以涵蓋的項目，就不必在每個溫度重測。

重測、分 bin 與資料

  • Bin：hard bin 是分料類別（良品、各類失效），soft bin 對應到具體的失效項目。分 bin 規則就是出貨規則，改動要走變更流程。
  • 重測：只允許特定的失效 bin 重測一次，通常是開路 / 短路、接觸類；並且追蹤「重測救回率」。救回率高代表接觸或 socket 有問題，不是元件有問題。參數或功能失效不應該靠重測「測到過」。
  • 站間比較：同一台 handler 各站的良率應該一樣。某一站良率明顯偏低，幾乎一定是那一站的 socket、接觸或 load board，要停下來查。
  • 統計良率與 bin 上限（SYL / SBL）：批次良率或某個 bin 的比例超出歷史範圍時暫停出貨，由工程判定。車用的 AEC-Q001（PAT）與 AEC-Q002 都要求這類統計管制，見生產章 PAT。
  • 資料：每顆每項的量測值以 STDF 格式保存，用於 SPC、追溯、客訴分析時調出當時的測試資料。
  • Golden unit 與相關性：每班用已知元件檢查機台；不同測試機、不同站之間定期比對，見相關性與 GR&R。大電流元件的特殊問題（接觸電阻、自熱、找跳脫點）見智慧開關的 ATE 難處。

可測試性設計（DFT）

  • 類比測試匯流排：把關鍵內部節點透過多工器引到一支測試腳或功能腳。
  • 修調暫存器的「試修」：先把修調碼寫入暫存器（不燒錄）量測結果，確定正確後才燒 OTP，降低燒錄錯誤。
  • 保護電路旁路：測試模式下暫時關閉 UVLO、軟啟動或熱關機延遲。
  • 數位掃描鏈：PMIC 的時序器與暫存器以 scan 測試，涵蓋率目標 > 95%。
  • 測試模式的安全性：要防止在客戶系統中被雜訊或錯誤的 I²C 命令誤觸。曾有產品因為上電時腳位雜訊誤入測試模式，造成現場輸出異常。

Kelvin 量測與大電流

測一顆 RDS(on) 30 mΩ 的開關時，socket 的接觸電阻可能就有 20–50 mΩ，而且會隨使用次數增加。解法是 Kelvin（四線）量測：一對 force 線送電流，另一對 sense 線在接腳上量電壓，sense 線幾乎沒有電流，接觸電阻不影響讀值。

  • Socket 磨耗：接觸電阻慢慢上升，RDS(on) 或負載調節率的分佈往一邊移動，最後造成良率下降或測試機之間不一致。要以 golden unit 每班檢查並設定更換次數。
  • 脈衝測試：大電流測試用 0.1–1 ms 脈衝，避免晶片自熱影響結果；也降低 socket 電弧與燒蝕。
  • 封裝內電阻：量到的 RDS(on) 包含打線與導線架。規格書通常列「包含封裝」的值，測試要說明量測點。

相關性與 GR&R

同一顆晶片在 CP、FT、實驗室、客戶產線上量到的值不會完全相同。相關性（correlation）就是要證明差異是已知且可接受的。

  • Golden unit：一組已在實驗室精確量測的樣品，用來校驗每台測試機、每個 load board。
  • GR&R（量測系統分析）：重複性（同一台重測）與再現性（不同台 / 不同人）佔公差的比例，< 10% 為佳，10–30% 視情況可接受，> 30% 不可接受。
  • Tester-to-tester：不同測試機的偏移要小於 guard band 的一部分，否則某台機台的良率會系統性偏低或偏高。
  • CP 對 FT：配對每顆晶粒的 CP 與 FT 資料，計算封裝偏移，用來校正 CP 修調目標（見生產 · CP 修調）。
  • 對客戶：客戶產線量到「超規」時，第一步是比較量測方法：負載、溫度、量測點、量測時間是否與規格書條件一致。

功能安全測試

  • 上電自我測試：監控比較器、參考電壓、看門狗在每次上電時自我檢查，失敗就不放行。
  • 故障注入：設計時在監控路徑上留下可注入故障的開關，量產與現場都能驗證監控電路本身沒壞（潛在故障）。
  • ATE 涵蓋率：功能安全要求量產測試涵蓋安全機制本身，否則安全機制的硬體缺陷不會被發現。
